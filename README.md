# SQL Assignments 🗄️

A structured collection of SQL queries, exercises, and database management assignments designed to practice and demonstrate proficiency in relational database concepts.

---

## 📂 Repository Structure

The repository contains the following directories and files:

*   **`a1/`**: Assignment 1 folder containing SQL scripts, queries, and related files for the first set of problems[cite: 2].
*   **`a2/`**: Assignment 2 folder containing intermediate SQL queries, joins, or database manipulation tasks[cite: 2].
*   **`a3/`**: Assignment 3 folder containing advanced SQL exercises, subqueries, or aggregate functions[cite: 2].
*   **`.gitignore`**: Specifies intentionally untracked files that Git should ignore.
*   **`README.md`**: Documentation providing an overview of the repository.

---

## 🚀 Topics Covered

*   **Data Definition & Manipulation (DDL & DML)**: Creating tables, inserting, updating, and deleting records.
*   **Queries & Filtering**: Using `SELECT`, `WHERE`, `ORDER BY`, `GROUP BY`, and `HAVING` clauses.
*   **Joins & Relationships**: Combining data across multiple tables using `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, etc.
*   **Advanced SQL**: Implementing subqueries, views, and aggregate functions.
